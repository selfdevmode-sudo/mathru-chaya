# Architecture Decision Records

Each file records one decision with lasting consequences: the context, the options considered, what was chosen, and why. ADRs are written **before** the affected work is implemented and amended (never rewritten) if a decision changes — a superseding ADR gets a new number and links back.

Format: Status · Context · Decision · Alternatives considered · Consequences.
